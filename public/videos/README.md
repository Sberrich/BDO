# Vidéos — emplacements réservés

## Accueil — bandeau « En vidéo »
| Fichier | Usage |
|---------|--------|
| `presentation.mp4` | Présentation Zakaria Fahim (home `#video`) |

1. Déposer le fichier ici : `public/videos/presentation.mp4`
2. Dans `lib/payload/site.ts` → `video.disponible: true`
3. Ajuster `duree` / `titre` / `texte` si besoin

Tant que `disponible` est `false`, le site affiche l’emplacement (poster) avec le badge **À venir**.

Fichier provisoire éventuellement présent : `ouverture-presenter.mp4` (ne pas brancher sur les héros).
